# Cornell box Renderer

Raytracing implementation starting from nothing rendering a cornell box.
Learning project used to understand lighting, shadows and basic ray object intersection.
Creation of basic multithreading, creation of different materials with reaction to light (Diffuse, mirror, glass)
Use of bounding boxes to reduce the number of useless rays.

## Classes

Most of the code can be found in LancerDeRayon.cpp, only a few classes are separated.
Pixel, rayon, and vector are simple classes created to facilitate the other function in the rest of the project.
